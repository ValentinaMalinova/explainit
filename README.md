# ExplainIt 1.2.2 — безплатен хостинг и AI с Gemini

Проектът съдържа образователен сайт с готови обяснения, интерактивни симулации и AI помощник.

## Какво е променено

- AI сървърната функция `api/ask.js` вече използва Google Gemini API вместо Anthropic/Claude.
- Използва се моделът `gemini-2.5-flash-lite`, който има безплатно ниво в Gemini API (при наличност и в рамките на текущите квоти на Google).
- Премахната е зависимостта `@anthropic-ai/sdk`. Не са нужни npm пакети за AI заявката.
- Ключът се чете само от променливата `GEMINI_API_KEY` на сървъра. Той не трябва да се поставя в `script.js`, `index.html` или GitHub.
- Запазени са съществуващите страници, стилове, интерактивности и интерфейсът към `/api/ask`.

## Публикуване без задължителни разходи

### 1. Google Gemini API ключ

1. Отвори [Google AI Studio](https://aistudio.google.com/).
2. Влез с Google профила си.
3. Отвори секцията за API ключове: [API keys](https://aistudio.google.com/apikey).
4. Създай API ключ за проект с безплатен достъп и го копирай.
5. Не го изпращай в чат, не го публикувай и не го добавяй в GitHub.

Важно: Gemini API има безплатно ниво с ограничения за заявки. Квотите зависят от модела, проекта и текущите условия на Google и могат да се променят. Не активирай платено таксуване, ако целта е разходът да остане нула. При достигане на квотата AI отговорите временно няма да работят, но готовите обяснения и останалата част от сайта ще продължат да работят.

### 2. Качване в GitHub

1. Създай ново хранилище (repository) в [GitHub](https://github.com/).
2. Качи съдържанието на тази папка, така че `index.html`, `script.js`, `style.css`, `topic.html`, `topic.css`, `topic.js`, `package.json` и папката `api` да са в основната директория на хранилището.
3. Направи Commit.

### 3. Публикуване във Vercel

1. Отвори [Vercel](https://vercel.com/) и избери регистрация/вход с GitHub.
2. Избери **Add New → Project** и импортирай хранилището ExplainIt.
3. За обикновен HTML/JS проект не е необходим Build Command. Остави настройките по подразбиране, ако Vercel разпознае проекта като статичен сайт.
4. Натисни **Deploy**.

### 4. Добавяне на Gemini ключа във Vercel

1. Отвори проекта във Vercel → **Settings → Environment Variables**.
2. Въведи име: `GEMINI_API_KEY`.
3. В стойност постави ключа от Google AI Studio.
4. Избери средата **Production** (можеш да избереш и Preview, ако ще тестваш preview версии).
5. Запази променливата.
6. Отвори **Deployments** и направи **Redeploy** на последното публикуване, за да се зареди новата променлива.

След това отвори сайта и задай въпрос, който не присъства в готовата библиотека, например „Защо металите провеждат електричество?“. Така ще се тества AI функцията.

## Важно за безплатното използване и поверителността

- Vercel Hobby е безплатният план за лични и некомерсиални проекти и има ограничения за употреба. Провери актуалните условия на [Vercel Pricing](https://vercel.com/pricing) и [Vercel Fair Use Guidelines](https://vercel.com/docs/limits/fair-use-guidelines).
- Безплатното ниво на Gemini API има квоти и условия, които Google може да променя. Виж [Gemini API Pricing](https://ai.google.dev/gemini-api/docs/pricing) и [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits).
- Според условията на безплатното ниво Google може да използва подаденото съдържание за подобряване на продуктите си. Не въвеждай лични данни, пароли, оценки, ученически профили или друга поверителна информация.
- API ключът е скрит от посетителите на сайта, но самият въпрос на посетителя се изпраща към Google Gemini за генериране на отговор.
- В `api/ask.js` има елементарно ограничаване на честотата на заявките. То е допълнителна защита, а не надежден глобален лимитер за serverless среда.

## Локална проверка

Можеш да отвориш `index.html` локално, за да провериш статичната част и готовите обяснения. AI функцията `/api/ask` изисква Vercel среда или локален сървър, който изпълнява Vercel Functions, както и зададена променлива `GEMINI_API_KEY`.
